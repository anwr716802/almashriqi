# مؤسسة المشرقي للنجارة والألمنيوم — موقع ثابت

## النشر
ارفع محتويات هذا المجلد إلى مشروع Vercel المرتبط بالنطاق `https://almashriqi-psi.vercel.app/` (ليس مضمونًا أن امتلاك الرابط يعني امتلاك صلاحية نشر المشروع). لا ترفع ZIP نفسه إذا كانت منصة النشر تتوقع ملفات المشروع.

## إعدادات التواصل
افتح `assets/js/main.js` وعدّل `SITE.facebook` و`SITE.maps` و`SITE.placeId` بالروابط والمعرفات الرسمية. الأزرار غير المكتملة مخفية. رقم الهاتف وواتساب مضمنان في صفحات HTML أيضًا؛ عند تغيير الرقم يجب تحديث كل الصفحات وإعادة النشر.

## الموقع الجغرافي
المقر المعروف هو **محافظة البيضاء** فقط، دون تحديد مدينة أو شارع. المناطق الأخرى في صفحة المناطق للاستفسار وليست فروعًا أو مناطق خدمة مؤكدة. حدّثها بناءً على نطاق الخدمة الفعلي.

## الصور
الرسومات المحلية SVG توضيحية وأصلية؛ ليست صور مشاريع منفذة. لتعويضها بصور فوتوغرافية مجانية، نزّل صورًا مرخصة من Unsplash أو Pexels، وراجع شروط كل صورة، وحوّلها إلى WebP ثم غيّر مسارات الصور في صفحات HTML. لم تُحمّل صور خارجية لأن الاتصال بمصادر الصور لم يكن متاحًا أثناء الإنشاء.

## تقييمات Google
الموقع لا يخترع مراجعات. بعد إضافة رابط خرائط Google سيظهر زر الوصول إلى المراجعات. المراجعات المباشرة داخل الموقع تحتاج إلى إعداد Google Places API وفق المتطلبات والفوترة وشروط الاستخدام؛ لا تضع مفتاح API سريًا في JavaScript العام.

## الفهرسة
أضف ملكية النطاق إلى Google Search Console، وأرسل `sitemap.xml`، واختبر الصفحات عبر فحص عنوان URL. الفهرسة والترتيب غير مضمونين.

## اختبار محلي
افتح `index.html` أو شغّل خادمًا محليًا بسيطًا. جرّب القائمة، النموذج، الروابط، والهواتف. تحقق من أداء الموقع عبر PageSpeed Insights بعد النشر.

## الصفحات
كل خدمة لها HTML مستقل. أضف صفحة جديدة ثم حدّث روابط القائمة و`sitemap.xml`. استخدم canonical وtitle ووصفًا فريدًا. لا تنشئ صفحات مناطق لا تقدم المؤسسة فيها خدمة حقيقية.
